# Bike Sharing EDA Project

Bu proje, UCI Bike Sharing veri seti kullanılarak günlük bisiklet kiralama talebinin keşifsel veri analizi ile incelenmesini amaçlamaktadır.

## Araştırma Sorusu

Hava durumu, mevsimsel ve zamansal faktörler bisiklet kiralama talebini nasıl etkiliyor?

## Veri Seti

UCI Machine Learning Repository - Bike Sharing Dataset

## Kullanılan Kütüphaneler

- pandas
- numpy
- matplotlib
- seaborn
- scipy

## Durum

Proje şu anda keşifsel veri analizi aşamasındadır. Makine öğrenmesi henüz projeye dahil edilmemiştir.
